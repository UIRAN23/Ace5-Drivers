# Ченджлог и канал обновлений

## Как написать текст

Используется Markdown. Никакие разделы «Что нового» и «Исправления» автоматически не добавляются.

```markdown
# Ace5 Fix 2.7.6

## Интерфейс
- **Плавная панель** реагирует на движение пальца.
- Исправлено отображение версии донора.

## Работа модуля
- Сохраняется выбранный режим.
- Используется каталог `modules_update`.

### Дополнительно
Любой свой абзац.
```

`# Заголовок`, `## Раздел`, `### Подраздел`: решётки и пробел ставятся перед текстом. Закрывать заголовок символами не нужно; форма `## Раздел ##` тоже поддерживается. `**слово**` делает текст жирным, обратные кавычки выделяют код, `- ` начинает пункт. HTML не выполняется.

Если поле Actions отображается в одну строку, используй `\n` для переноса:

```text
## Интерфейс\n- **Плавнее** переключение.\n\n## Скрипты\n- Сохранение режима.
```

Вертикальная черта `|` остаётся обычным символом. В WebUI поддерживаются заголовки, пункты, жирный текст и код. Показываются первые 200 строк.

## Где редактировать

- В приватном ace5-fix: «4 · Опубликовать в зеркало» → одно обязательное поле `changelog`. Текст относится к выбранному ZIP. Публикация архива требует отдельного подтверждения и сейчас не запускалась.
- В публичном Ace5-Drivers: «Изменить ченджлог текущей версии» → поле `changelog`. Меняется только текст текущей публичной версии. Не пиши здесь изменения ещё не опубликованного ZIP.

Текст сохраняется в `changelogs/vX.Y.Z.md`; `changelog.md` остаётся совместимой копией последней записи. `update.json` указывает на соответствующий Markdown. Номер версии, URL архива и его SHA-256 не меняются при редактировании заметок.

## Автоматическое определение типа

`versionCode` определяет наличие обновления модуля. `updateType` содержит `webui`, `scripts` либо `module`. Публикующий Actions сравнивает хэши групп файлов с прошлой публикацией; тексты заметок и метаданные версии исключены из сравнения. Если прежних хэшей нет или изменились обе группы, используется общее «Обновление модуля». Тип не угадывается по словам в ченджлоге.

ODM проверяется отдельно через Daniel API с резервом OnePlus. При двух обновлениях оба результата видны на одном экране; после подготовки одного требуется перезагрузка перед следующим. Обои соответствуют доступному донору и не переключаются при появлении обновления WebUI.

Публичная запись сейчас остаётся v2.6.2. Ни один новый ZIP этим изменением не опубликован.
