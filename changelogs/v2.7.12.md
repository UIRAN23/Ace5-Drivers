# Ace5 Fix 2.7.12

## NoMount

- Исправлена остановка камеры при ошибке Android Binder: ограниченные по времени am/cmd, затем резерв только для проверенных процессов com.oplus.camera.
- Службы камеры определяются по текущему init.svc. Перезапуск подтверждается сменой PID или переходом в running, отправленный запрос сам по себе не считается успехом.
- Результат горячего применения и этап сохраняются в module.prop. Ошибка остаётся видна в WebUI даже после завершения установки NoMount 2.0.0.
- Ручное применение без перезагрузки блокируется, пока ожидает обновление модуля или ODM.
- Новые permissions и профили зарядки/температуры требуют перезагрузки. Последующие обновления только кода при неизменном ODM сохраняют горячую установку NoMount.

## Весь комплект оригинала

В пакет возвращены оба исключённых файла: теперь включены все **113 файлов ODM** из предоставленного оригинального архива с исходными байтами. При установке исправляется только известный crypto XML с двумя корнями — обе записи library остаются. fake_camera_extensions.xml сохранён без изменений; отсутствующая библиотека пропускается Android 16.

Донор по-прежнему **PKG110 16.0.10.500**. Версия ColorOS не изменилась.

Supolicy не добавлен. Поведение на телефоне требует проверки. Это заметки приватной сборки; публичный ZIP и канал обновлений не изменены.
