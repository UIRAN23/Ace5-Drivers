# Ace5 Fix 2.7.11

## Интерфейс и медиа

- Кнопки и нижняя панель растягиваются по направлению движения пальца с мягким возвратом.
- Домик на главной; плавное заполнение иконок. Прежняя вкладка перестаёт подсвечиваться при выборе другой.
- Фото и видео сохраняются в фоне с процентами по записанным байтам; WebUI остаётся доступным во время записи.
- Предпросмотр появляется до окончания сохранения. Повторное кадрирование меняет положение медиа без повторной передачи файла.
- Файлы находятся в `/data/adb/Ace5fix/media`; в модуле остаются только ссылки для быстрого открытия. В базе WebView сохраняются метаданные без второй копии видео.
- Экспорт темы на телефоне копирует сохранённые медиа напрямую, без загрузки всего видео в память WebUI.

## Набор ODM

Донор остаётся **PKG110 16.0.10.500**. Версия ColorOS не меняется.

Набор расширен с 59 до 111 файлов: добавлены devices_config, permissions, сенсоры, thermal и fastchg из предоставленного оригинала 2.8 beta. Прежние 59 файлов камеры не изменены. Две некорректные декларации оригинала исключены: XML с двумя корневыми элементами и ссылка на отсутствующий JAR.

Обновление сохраняет установленный донор. Для той же версии дополняются только недостающие файлы; более новый донор не смешивается со старым. Неполный набор определяется отдельно от новой версии: апдейтер предлагает «Дополнение ODM» даже при совпадении версий. Штатные файлы новых каталогов сохраняются при монтировании.

Первое добавление профилей зарядки и температуры требует перезагрузки. Работу камеры, сенсоров и зарядки необходимо проверить на телефоне.

Это заметки приватной тестовой сборки. Публичный ZIP и канал обновлений не изменены.
